# 17. Заказы парсера МА

**ФУНКЦИОНАЛ ДО КОНЦА НЕ ДОРАБОТАН**

# Общее описание

Название проводки: ORDER

Документ описывает формат json-файла, который передается от Битрикс 24 в 1С Управление торговлей. На сервере Битрикс 24 расположен парсер Мой агент, интеграция именно с ним, а не с Битрикс 24.

Идентификация: Basic auth

Тип сервиса: REST API

Метод HTTP: POST

URL метода: 

1С.УТ ТЕСТ: https://10.30.88.24/TRADE/hs/PARSER\_Exchange/Order

1С.УТ ПРОД: https://10.30.88.24/TRADE\_WORK/hs/PARSER\_Exchange/Order

# Логика работы

Б24 вызывает сервис    https://#IP#/#база 1с#/hs/PARSER\_Exchange/Order  и передает на вход  json-файл со следующими данными
